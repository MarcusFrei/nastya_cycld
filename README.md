# Цикл и Энергия — Android-приложение (Kotlin + Jetpack Compose)

Нативное Android-приложение: календарь женского цикла с трекером уровня
энергии по 5 цветам, автоматическим расчётом фазы цикла, приблизительной
оценкой вероятности зачатия, статистикой (график энергии, стабильность
цикла) и настраиваемым внешним видом (светлая/тёмная тема, пресеты фона).

## ⚠️ Важно про сборку .apk

Этот код не был скомпилирован мной — у меня нет доступа к Android SDK и
серверам Google в этой среде. Зато ниже — рабочий способ получить готовый
`.apk`, ничего не устанавливая на свой компьютер.

## Способ 1 (рекомендуется) — автоматическая сборка через GitHub Actions

1. Создайте новый **публичный или приватный** репозиторий на github.com
2. Загрузите туда все файлы из этой папки (сохраняя структуру, включая
   скрытую папку `.github`)
3. Зайдите во вкладку **Actions** репозитория — сборка запустится
   автоматически (или нажмите "Run workflow" вручную, если не запустилась)
4. Через 3-5 минут откройте завершившийся запуск → внизу страницы будет
   раздел **Artifacts** → скачайте `cycle-app-debug-apk.zip`
5. Внутри — файл `app-debug.apk`. Перекиньте его на телефон и установите
   (может понадобиться разрешить "Установка из неизвестных источников" в
   настройках Android)

Ничего вручную настраивать не нужно — вся сборка (включая Android SDK)
происходит на серверах GitHub бесплатно.

## Способ 2 — сборка в Android Studio на своём компьютере

1. Установите [Android Studio](https://developer.android.com/studio)
2. File → Open → выберите папку проекта `CycleApp`
3. Дождитесь Gradle Sync (первый раз может занять несколько минут —
   скачиваются зависимости)
4. Build → Build Bundle(s) / APK(s) → Build APK(s)
5. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`

Если Android Studio предложит создать/обновить Gradle Wrapper — согласитесь,
это нормально (в проекте специально не зашит бинарный `gradle-wrapper.jar`,
Android Studio сгенерирует его сама).

## Что изменено в v1.4

- **Темы**: убран выбор акцентных цветов. Остались «Светлая», «Тёмная», «Системная», а все цвета (кнопки, выделения, текущий день) подбираются под выбранный фон. Фоны только пастельные: розовый, бежевый, голубой, зелёный, сиреневый. Тёмная тема строится из того же фона — тот же оттенок, но глубокий
- **Карточка дня без кнопки «Сохранить»**: энергия, настроение, симптомы и месячные сохраняются сразу при нажатии, заметка — через полсекунды после ввода. Энергия вынесена наверх, окно открывается на весь экран, «Очистить день» — значок корзины в шапке
- **Блок «Цикл» стал компактнее и понятнее**: вместо большого столбца — шкала цикла (по полоске на день: месячные, фертильные дни, овуляция; сегодня выделено), строка «День 2 из 28 · до месячных 27 дн.» и подсказка по фазе
- **Цифра в маркере энергии** теперь по центру кружка
- **Обновление без «конфликта пакетов»**: сборка подписывается общим ключом (`app/cycleapp-shared.keystore`), а `versionCode` растёт с каждым запуском GitHub Actions. Раньше каждая сборка получала случайный debug-ключ, и Android отказывался ставить её поверх старой
- **Экспорт и импорт журнала** (Настройки → «Журнал»): все отметки сохраняются в JSON-файл и загружаются обратно — «объединить» или «заменить»

> Первый переход на эту версию нужно сделать через удаление старой (она подписана другим ключом). Дальше обновления ставятся поверх без удаления.

## Что изменено в v1.3 — автоматический прогноз и новый дизайн по макетам

**Прогноз больше не зависит от ручных настроек**
- Убран ввод «длина цикла» и «длина менструации» (раньше они были зашиты в настройки и ломали прогноз, особенно если реальный цикл отличался от 28 дней)
- Длина цикла и месячных теперь считается автоматически по отметкам: берутся последние 6 циклов, свежие весят больше, случайные выбросы отсеиваются. Пока данных нет — типовые 28/5 дней, после 2–3 отмеченных циклов расчёт подстраивается под вас
- Прошлые циклы разбираются по их фактической длине (раньше все дни считались по одной «усреднённой» длине)
- Задержка показывается как задержка («задержка 3 дн.»), а не «перескакивает» на следующий цикл
- Разрыв в 1–2 дня внутри месячных не делит период на два цикла
- В прогнозе показывается погрешность (±N дн.) и по скольким циклам он построен; в настройках — текущие расчётные значения
- Новые быстрые кнопки: «Начались месячные» / «Сегодня идут» / «Месячные закончились» — не нужно отмечать каждый день вручную

**Читаемые цветные значки**
- Энергия — отдельный круглый маркер с цифрой 1–5 и тёмной обводкой под числом (больше не заливает всю ячейку; цвет продублирован цифрой, «норма» видна на светлом фоне)
- Месячные: факт — сплошной круг, прогноз — пунктирное кольцо; овуляция — сплошной бирюзовый круг, фертильные дни — зелёное кольцо. Мелкие ★ и эмодзи 🌱 заменены на крупные понятные значки
- Легенда нарисована теми же кругами, что и календарь
- Цвет текста на кнопках выбирается по контрасту с акцентом (раньше белый на пастельных акцентах не читался)

**Оформление по макетам**
- Светлый нежно-розовый фон по умолчанию, крупные скруглённые карточки
- Главный экран «Цикл»: приветствие, карточка дня с графиком длительности последних месячных, плитки «Следующие месячные» и «Овуляция», быстрая отметка энергии
- Нижняя навигация с круглой кнопкой «+» (отметить сегодня); «Уведомления» переехали в «Настройки»
- Календарь в круглых ячейках, смена месяца свайпом
- В карточке дня: интенсивность месячных (слабые/средние/обильные), настроение и симптомы в виде чипов

## Что изменено по второму раунду обратной связи (v1.2)

- **Текст в тёмной теме починен по-настоящему** — причина была в прозрачном фоне Scaffold, из-за которого часть текста брала цвет по умолчанию (чёрный) вместо цвета темы. Теперь исправлено на корневом уровне + явные цвета расставлены везде
- **Фон полностью независим от темы** — тема (светлая/тёмная/системная) теперь влияет **только** на цвет текста и иконок, а сам фон определяется только выбранным пресетом. Пресетов стало 14, включая светлые (Ваниль, Мята, Небо, Персик, Сирень, Пудра светлая) и тёмные
- **Симптомы и настроение** — в карточке дня теперь можно отметить настроение (6 вариантов с эмодзи) и симптомы (10 вариантов: спазмы, головная боль, вздутие и т.д.). Дни с такими отметками помечены маленькой точкой в календаре
- **Блок менструации** — текст теперь центрирован, отступы одинаковые со всех сторон (12dp)
- **Отладочное меню** — в настройках новая карточка «Отладка» с кнопкой полной очистки всех данных (с подтверждением)
- **Формат даты** — везде теперь день.месяц.год (например, 10.07.2026)
- **Список цветов энергии** — вместо чипов в две строки теперь компактный вертикальный список
- **Порядок блоков** — календарь теперь сразу после карточки фазы, прогноз — в самом низу экрана
- **Уведомления** — отдельная вкладка с 4 переключателями (за неделю до месячных, за день до месячных, за неделю до овуляции, каждый день менструации) и настраиваемым часом напоминания. Уведомления пересчитываются автоматически при изменении данных цикла

## Что изменено по вашей обратной связи (v1.1)

- **Текст в тёмной теме** — теперь всегда светлый (белый/светло-лиловый), гарантированный контраст на любом фоне
- **Фон и элементы согласованы** — карточки, кнопки, навигация теперь берут цвет из выбранного пресета фона (раньше оставались фиолетовыми независимо от фона)
- **Цвет «норма»** — заменён с белого на тёплый бежевый, чтобы был виден в светлой теме
- **Календарь больше не "прыгает"** — сетка всегда фиксированной высоты (6 строк), независимо от количества дней в месяце
- **Новые пресеты фона**: Пудра (розовый) и Карамель (бежевый) — в дополнение к существующим
- **Отдельный акцентный цвет** — теперь можно выбрать цвет выделений/кнопок отдельно от фона: фиолетовый, розовый, бежевый, пудровый, мятный, голубой
- **Окончание менструации** — переключатель переименован в «Менструация в этот день»; отмечайте каждый день цикла — начало и конец диапазона определяются автоматически. В статистике появилась «Средняя длительность месячных» на основе реальных диапазонов
- **Блок прогноза** — на главном экране показывает ожидаемую дату следующих месячных, примерную фазу и уровень энергии за неделю до них (на основе исторических данных), с пометкой о возможной раздражительности/ПМС

## Функциональность

- **Календарь цикла** — месячная сетка, отметка дня начала менструации,
  визуальные маркеры дня овуляции
- **Энергия 5 цветами**: красный (минимум) / жёлтый (ниже нормы) / белый
  (норма) / зелёный (выше нормы) / синий (пик)
- **Автофаза цикла**: менструация / фолликулярная / овуляция / лютеиновая,
  рассчитывается по последней отмеченной менструации + длине цикла
- **Вероятность забеременеть** — приблизительная оценка календарным методом
  относительно дня овуляции (очень низкая → пиковая). Это не медицинский
  метод контрацепции, в приложении есть соответствующая пометка
- **Статистика**:
  - столбчатый график уровня энергии за последние 30 дней
  - средняя длина цикла, мин/макс, регулярность (по стандартному отклонению
    между циклами)
  - график длины последних циклов
  - средний уровень энергии по фазам цикла
- **Настройки**: уведомления, светлая/тёмная/системная тема, акцентный цвет,
  15 пресетов фона. Длина цикла и менструации вычисляются автоматически
- Все данные хранятся локально на устройстве (Jetpack DataStore), никуда
  не передаются

## Технологии
